# วิธีติดตั้ง StepCap / How to install StepCap

คัดลอกข้อความด้านล่างไปวางในแชตหรืออีเมล แล้วแนบไฟล์ `StepCap-Setup-1.0.0.exe` ไปด้วย
(Copy the text below into a chat or email and attach `StepCap-Setup-1.0.0.exe`.)

---

**StepCap** — โปรแกรมบันทึกการคลิกเป็นคู่มือทีละขั้นตอนพร้อมภาพ ทำงานในเครื่องเท่านั้น ไม่ส่งข้อมูลออกไปที่ไหน

วิธีติดตั้ง (ไม่ต้องใช้สิทธิ์ admin):
1. ดับเบิลคลิกไฟล์ `StepCap-Setup-1.0.0.exe`
2. ถ้าขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway**
   (ขึ้นเพราะโปรแกรมนี้ยังไม่ได้ซื้อใบรับรองจาก Microsoft ไม่ใช่ไวรัส)
3. เลือกภาษา **ไทย** แล้วกด **ตกลง** (หรือ **OK**) StepCap จะใช้ภาษานี้ด้วย
4. กด **ถัดไป** แล้วกด **ติดตั้ง**
5. กด **เสร็จสิ้น** StepCap จะเปิดขึ้นมา ครั้งต่อไปเปิดได้จากเมนู Start หรือไอคอนบนเดสก์ท็อป

คู่มือที่ทำจะเก็บอยู่ที่ `Documents\StepCap` ถ้าถอนการติดตั้ง (Settings > Apps) คู่มือจะยังอยู่
เวลาส่งคู่มือให้คนอื่น ให้ส่งเฉพาะไฟล์ที่กด **ส่งออก** อย่าส่งทั้งโฟลเดอร์

---

**StepCap** turns your clicks into a step-by-step guide with pictures. Everything stays on your computer.

To install (no admin rights needed):
1. Double-click `StepCap-Setup-1.0.0.exe`.
2. If a blue "Windows protected your PC" screen appears, click **More info**, then **Run anyway**.
   (It shows because this program isn't signed with a paid Microsoft certificate yet. It is not a virus.)
3. Choose **English** and click **OK**. StepCap will use this language too.
4. Click **Next**, then **Install**.
5. Click **Finish** and StepCap opens. Next time, open it from the Start menu or the desktop icon.

Your guides are kept in `Documents\StepCap`. Uninstalling (Settings > Apps) keeps them.
When you share a guide, send only the file you made with **Export**, never the whole folder.
