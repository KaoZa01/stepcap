# StepCap — ส่วนที่ 2: ตัวแก้ไขภาพ

สถานะ: ผ่านผู้ตรวจแล้ว รอผู้ใช้อนุมัติ · ครอบคลุม "ส่วนที่ 2" จากทั้งหมด 6 ส่วน · ต่อจาก `2026-10-15-app-window-home-viewer-design.md` (ส่วนที่ 0+1 สร้างและผู้ใช้ทดสอบผ่านแล้ว)

## 1. ที่มาและเหตุผล

StepCap บันทึกขั้นตอนพร้อมภาพหน้าจอและวงจุดคลิกได้แล้ว ก่อนส่งคู่มือให้คนอื่น ผู้ใช้ต้องแต่งภาพ เช่น ปรับขนาดวง ชี้ด้วยลูกศร ใส่ข้อความ และซ่อนข้อมูลส่วนตัว ตอนนี้ทำได้แค่เพิ่ม/ลาก/ลบวง เปลี่ยนสีกับขนาดทีละวง และครอป

ผู้ใช้เลือกฟีเจอร์ Pro ของ Scribe ที่ไม่ใช้ AI ไว้แล้ว ส่วนนี้คือข้อ #7 รูปทรงจุดคลิก, #8 วาดลูกศร/กรอบ/ข้อความ, #9 เบลอ/ปิดดำ, #11 เปลี่ยน/เพิ่มภาพและ GIF, #12 ดาวน์โหลดภาพ

**สิ่งที่ผู้ใช้ขอเพิ่มเอง:** "แก้วงกลมโดยปรับขนาดทีเดียวได้ทั้งหมด" คือปรับขนาดวงทุกวงในคู่มือได้ในครั้งเดียว เหมือนที่เปลี่ยนสีทั้งคู่มือได้แล้ว

## 2. สิ่งที่มีอยู่แล้ว (ที่เกี่ยวกับส่วนนี้)

- **`ui/guide.js`:**
  - `drawStepCanvas(canvas, img, step, maxW)` วาดภาพของขั้นตอนตาม `crop` (จำกัดให้อยู่ในขอบภาพ) แล้ววาดวงทับ
  - `renderGuide(guide, root)` ใช้ในโหมดดูและในไฟล์ Export ทั้งสองฟังก์ชันต้องไม่พึ่งฟังก์ชันอื่น เพราะ Export แปลงโค้ดทั้งสองเป็นข้อความแล้วฝังลงในไฟล์
  - `imageEditor(step)` คือเครื่องมือแก้ภาพในการ์ดขั้นตอนของโหมดแก้ไข ได้แก่ เพิ่มวง ลากวง สี/ขนาด/ลบรายวง และครอป
  - แถบเครื่องมือลอยมีปุ่ม "สีวงจุดคลิก" (`setClickColor` เปลี่ยนทุกวงในคู่มือ) และ "ตั้งค่าเอกสาร"
- **`exportGuide(gid)`:** ฝังภาพต้นฉบับเป็น data URL แล้วให้ `renderGuide` วาดวงทับตอนเปิดไฟล์ บันทึกผ่านหน้าต่าง "บันทึกเป็น" ที่ `POST /api/guide/<id>/export`
- **`app.py`:** `/img/<id>/<file>` ส่งไฟล์ภาพโดยตอบประเภทเป็น `image/png` เสมอ
- **`library.py`:** `normalize()` เติมค่าเริ่มต้นให้คู่มือเก่า, `_is_guide()` ตรวจรูปแบบไฟล์ และ `DEFAULT_SETTINGS` มี `click_color`
- **ข้อมูลขั้นตอนตอนนี้:**

  ```json
  { "id": "s1a2b3c4", "kind": "click|...|note", "text": "...",
    "image": "s1a2b3c4.png" | null, "crop": null | {"x","y","w","h"},
    "markers": [ {"x","y","color","size"} ] }
  ```

  พิกัดทุกค่าเป็นพิกเซลจริงของภาพเต็ม ไม่ใช่พิกเซลบนจอ

## 3. เป้าหมาย (ผู้ใช้ตกลงตามที่สรุปให้แล้ว)

### 3.1 จุดคลิกทั้งคู่มือ
- ปุ่ม "สีวงจุดคลิก" ในแถบเครื่องมือลอยกลายเป็นปุ่ม **"จุดคลิก"** กดแล้วเลือกได้ 3 อย่าง:
  - **สี:** ชุดสีเดิมและช่องเลือกสีเอง
  - **รูปทรง:** วงกลมหรือสี่เหลี่ยม
  - **ขนาด:** แถบเลื่อน
- เลือกอย่างใดแล้ว**เปลี่ยนทุกวงในคู่มือทันที** และวงที่เพิ่มใหม่หลังจากนั้นใช้ค่าเดียวกัน
- ยังแก้สี ขนาด และรูปทรงทีละวงได้เหมือนเดิม

### 3.2 หน้าต่างแก้ภาพ
- กด **"แก้ไขภาพ"** ที่การ์ดขั้นตอน (เฉพาะขั้นตอนที่มีภาพ) แล้วภาพนั้นจะเปิด**เต็มหน้าต่างของโปรแกรม** ไม่ใช่หน้าต่างใหม่
- แถบเครื่องมือด้านบนมี:
  - **จุดคลิก:** เพิ่มวง ลากย้าย ลบ
  - **ลูกศร:** ลากจากจุดเริ่มไปจุดปลาย
  - **กรอบ:** สี่เหลี่ยมเส้นขอบ
  - **ข้อความ:** คลิกตรงไหนแล้วพิมพ์
  - **เบลอ** และ **ปิดดำ:** ลากเป็นสี่เหลี่ยมคลุมส่วนที่จะซ่อน
  - **ครอป**
  - **ย้อนกลับ** (Ctrl+Z)
  - **เปลี่ยนภาพ**
  - **ดาวน์โหลดภาพ**
  - **เสร็จ**
- ทุกปุ่มมี tooltip ภาษาไทย
- คลิกเลือกสิ่งที่วาดไว้ได้ เมื่อเลือกแล้วลากย้าย แก้สี หรือกด Delete เพื่อลบได้

### 3.3 เปลี่ยนภาพ / เพิ่มภาพ / GIF
- **เปลี่ยนภาพของขั้นตอน:** ใช้ไฟล์ PNG, JPG หรือ GIF หรือ**วางจากคลิปบอร์ด (Ctrl+V)**
- **เพิ่มขั้นตอนใหม่ที่เป็นภาพหรือ GIF:** มีช่องคำอธิบาย
- **GIF:** แสดงเป็นภาพเคลื่อนไหวทั้งในโหมดดูและในไฟล์ Export แต่ใส่วง ลูกศร กรอบ ข้อความ หรือเบลอบน GIF ไม่ได้

### 3.4 ดาวน์โหลดภาพ
- แต่ละขั้นตอนบันทึกภาพเป็น PNG ผ่านหน้าต่าง "บันทึกเป็น" ของ Windows
- ภาพที่ได้มีครบทุกอย่างที่เห็น ได้แก่ ครอป วง ลูกศร กรอบ ข้อความ และส่วนที่เบลอหรือปิดดำ
- ขั้นตอนที่เป็น GIF บันทึกเป็นไฟล์ GIF เดิม

### 3.5 การซ่อนข้อมูลต้องลบออกจากภาพจริง (ข้อห้ามพลาดที่ผู้ใช้รับทราบ)
- ในไฟล์ Export และภาพที่ดาวน์โหลด ส่วนที่เบลอหรือปิดดำต้อง**ไม่มีพิกเซลเดิมเหลืออยู่ในไฟล์เลย** การวางแผ่นปิดทับภาพต้นฉบับที่ยังฝังอยู่ในไฟล์ถือว่าผิด
- **ภาพต้นฉบับในเครื่องยังเก็บไว้:** ยกเลิกการเบลอหรือย้ายกรอบเบลอทีหลังได้

## 4. สิ่งที่ไม่ทำในรอบนี้ และสิ่งที่ห้ามเกิดขึ้น

**ไม่ทำในรอบนี้**
- ซ่อนข้อมูลอัตโนมัติ (ส่วนที่ 3) แต่ข้อมูลเบลอ/ปิดดำในรอบนี้ต้องให้ส่วนที่ 3 เพิ่มรายการเข้าไปได้ ดูข้อ 6
- ทำซ้ำ (redo)
- ปากกาวาดอิสระ สติกเกอร์ หมุนภาพ ปรับขนาดภาพ
- ใส่วงหรือลูกศรบน GIF
- หลายภาพในขั้นตอนเดียว
- ลบไฟล์ภาพเก่าที่ไม่ได้ใช้แล้วออกจากโฟลเดอร์คู่มือ
- AI ทุกชนิด

**ห้ามเกิดขึ้น ถ้าเกิดถือว่างานล้มเหลวแม้โค้ดจะทำงานได้**
- ไฟล์ Export หรือภาพที่ดาวน์โหลดยังมีพิกเซลเดิมของส่วนที่เบลอหรือปิดดำ ไม่ว่าจะซ่อนอยู่ในรูปแบบใด
- คู่มือเดิมเปิดไม่ได้ วงหาย หรือครอปเพี้ยน
- เครื่องมือรายวงและการครอปที่มีอยู่ใช้ไม่ได้
- มีหน้าต่างเบราว์เซอร์เปิดขึ้นมา หน้าต่างเลือกไฟล์หรือบันทึกไฟล์ของ Windows ใช้ได้
- รับไฟล์ที่ไม่ใช่ภาพแล้วบันทึกลงโฟลเดอร์คู่มือ
- การแก้ภาพทำให้ภาพต้นฉบับในเครื่องถูกเขียนทับ

## 5. ข้อจำกัด
- ใช้สิ่งที่มีอยู่: Python 3.14 ใน `.venv`, pywebview/WebView2 และ canvas ของหน้าเว็บ **ห้ามเพิ่ม dependency ใหม่**
- ข้อความบนหน้าจอเป็นภาษาไทยทั้งหมด ธีมสว่าง
- ทำงานในเครื่องเท่านั้น
- `renderGuide` และฟังก์ชันวาดที่มันเรียกต้องฝังลงไฟล์ Export ได้ คือไม่พึ่งตัวแปรหรือฟังก์ชันอื่นของหน้า
- เทสต์เดิมทั้งหมดต้องยังผ่าน (`test_steps`, `test_library`, `test_windows`, `test_app`)
- ตรรกะใหม่ที่ไม่ง่ายต้องมีเทสต์ที่รันได้ ได้แก่ การตรวจและบันทึกไฟล์ภาพที่อัปโหลด, ค่าเริ่มต้นของฟิลด์ใหม่ และการพิสูจน์ว่าไฟล์ Export กับภาพที่ดาวน์โหลดไม่มีพิกเซลเดิมในส่วนที่ซ่อน
- เทสต์ห้ามจำลองการคลิกหรือพิมพ์บนเดสก์ท็อปจริง และต้องใช้ที่เก็บชั่วคราว (`STEPCAP_STORAGE`)

## 6. สิ่งที่ผู้ออกแบบตัดสินใจเอง (ผู้ใช้ไม่ได้เป็นคนเลือก)

**ข้อมูลที่เพิ่มในขั้นตอนและในคู่มือ**

```json
"markers":     [ {"x","y","color","size","shape": "circle"|"rect"} ],
"annotations": [ {"type":"arrow","x1","y1","x2","y2","color","width"}
               | {"type":"box","x","y","w","h","color","width"}
               | {"type":"text","x","y","text","color","size"} ],
"redactions":  [ {"type":"blur"|"black","x","y","w","h"} ],
"settings":    { ..., "click_shape": "circle", "click_size": 44 }
```

- ทุกพิกัดเป็นพิกเซลของภาพเต็ม แบบเดียวกับ `markers` เดิม แล้วครอปตอนวาด
- **ค่าเริ่มต้นของคู่มือเก่า:** วงที่ไม่มี `shape` ใช้ `circle`, ขั้นตอนที่ไม่มีลิสต์ใหม่ใช้ `[]`, และ `click_shape`/`click_size` ใช้ค่าเริ่มต้น โดยเติมใน `library.normalize` ตอนอ่าน และไม่เขียนลงไฟล์จนกว่าจะมีการบันทึก
- **ทำไมแยก `redactions` จาก `annotations`:** ส่วนที่ 3 จะเพิ่มรายการเบลออัตโนมัติลงลิสต์นี้ และลำดับการวาดต่างกัน
- **ลำดับการวาด:** ภาพ → เบลอ/ปิดดำ → กรอบ/ลูกศร/ข้อความ → วงจุดคลิก

**รูปทรงสี่เหลี่ยมของจุดคลิก**
- เป็นสี่เหลี่ยมจัตุรัสมุมมนขนาด `size` × `size` ไม่ใช่สี่เหลี่ยมผืนผ้าที่กำหนดกว้างยาวเอง เพื่อให้แถบเลื่อนขนาดเดียวใช้ได้กับทุกวง

**ค่าเริ่มต้นของเครื่องมือวาด**
- สีของลูกศร กรอบ และข้อความใช้สีจุดคลิกของคู่มือ และเปลี่ยนได้จากชุดสีเดียวกัน
- เส้นมี 3 ขนาด: บาง กลาง หนา
- ข้อความมี 3 ขนาด ใช้ตัวอักษรที่มีภาษาไทย และมีขอบสีขาวรอบตัวอักษรเพื่อให้อ่านได้บนทุกพื้น

**การเบลอ**
- เบลอแรงพอที่ตัวอักษรใต้กรอบอ่านไม่ออก
- ถ้าต้องการให้หายแน่นอน ให้ใช้ "ปิดดำ"

**การแก้ไขบันทึกเมื่อไร**
- ทุกการเปลี่ยนแปลงเข้าคู่มือทันทีและบันทึกอัตโนมัติแบบเดิม ปุ่ม "เสร็จ" แค่ปิดหน้าต่างแก้ภาพ
- **ย้อนกลับ (Ctrl+Z):** ย้อนได้หลายครั้งภายในการเปิดหน้าต่างแก้ภาพครั้งนั้น นับรวมการเปลี่ยนภาพด้วย ประวัติหายเมื่อปิดหน้าต่าง

**การเปลี่ยนภาพ**
- เปลี่ยนภาพแล้วล้างครอป วง ลูกศร กรอบ ข้อความ และเบลอของขั้นตอนนั้น เพราะเป็นภาพคนละภาพ และยังย้อนกลับได้
- ไฟล์ภาพเดิมไม่ถูกลบ ซึ่งเป็นเหตุผลที่ย้อนกลับได้

**Ctrl+V**
- ในหน้าต่างแก้ภาพ: แทนภาพของขั้นตอนนั้น
- ในหน้าแก้ไขคู่มือ เมื่อไม่ได้พิมพ์อยู่ในช่องข้อความ: เพิ่มขั้นตอนภาพใหม่ต่อท้าย

**ขั้นตอนภาพใหม่**
- ใช้ `kind: "image"` มีเลขขั้นตอนและนับรวมเหมือนขั้นตอนปกติ ส่วน `text` เป็นคำอธิบาย
- ป้ายประเภทภาษาไทยคือ "ภาพ"
- ปุ่ม **"+ เพิ่มภาพ"** อยู่ข้างปุ่ม "+ เพิ่มหมายเหตุ"

**การรับไฟล์ภาพ (ฝั่ง server)**
- ตรวจจากไบต์ต้นไฟล์ ไม่เชื่อนามสกุล: PNG, JPEG และ GIF เท่านั้น
- ขนาดไม่เกิน 25 MB
- ตั้งชื่อไฟล์ใหม่เองในโฟลเดอร์คู่มือ
- `/img/...` ต้องตอบประเภทไฟล์ตามชนิดจริง ไม่ใช่ `image/png` ทุกครั้ง

**วิธีลบพิกเซลจริงตอน Export และดาวน์โหลด**
- ทุกขั้นตอนที่ไม่ใช่ GIF ถูกวาดเสร็จเป็น PNG ก่อน (ครอป เบลอ ลูกศร และวงลงไปแล้ว) แล้วฝังภาพนั้นแทนภาพต้นฉบับ
- ข้อมูลครอป วง และลายเส้นถูกตัดออกจากไฟล์ เพราะวาดลงภาพแล้ว
- ทำกับทุกขั้นตอน ไม่เฉพาะขั้นตอนที่มีเบลอ เพื่อให้มีกฎเดียวและไม่มีภาพต้นฉบับหลุดไปในไฟล์ส่งออกเลย
- ดาวน์โหลดภาพใช้ภาพที่วาดเสร็จแบบเดียวกัน

**ปุ่มดาวน์โหลดภาพ**
- อยู่ในหน้าต่างแก้ภาพ และในเครื่องมือของการ์ดขั้นตอนในโหมดแก้ไข
- ชื่อไฟล์ตั้งต้นคือ `<ชื่อคู่มือ> - ขั้นตอน <เลข>.png`

**จุดที่ผู้ตรวจถาม และผู้ออกแบบตัดสินเอง**
- **ขั้นตอน GIF:** ครอป เบลอ และปิดดำไม่ได้ด้วย เพราะ GIF ถูกส่งออกและดาวน์โหลดเป็นไฟล์เดิมตามข้อ 3.3–3.4 ถ้ายอมให้เบลอได้จะขัดกับข้อ 3.5
- **"ไม่มีพิกเซลเดิม" แปลว่า:** ข้อมูลภาพต้นฉบับต้องไม่ปรากฏในไฟล์ส่งออกหรือภาพที่ดาวน์โหลดเลย ส่วนพิกเซลในกรอบที่ซ่อนต้องสร้างใหม่จากการเบลอหรือการปิดดำ เทสต์ใช้ภาพสัญญาณรบกวนแบบสุ่ม แล้วตรวจว่าพิกเซลในกรอบเปลี่ยนไป และไม่มีข้อมูลภาพเดิมอยู่ในไฟล์
- **สี รูปทรง และขนาดของคู่มือใช้กับวงจุดคลิกเท่านั้น:** ลูกศร กรอบ และข้อความใช้สีคู่มือเป็นสีตั้งต้นตอนวาด แล้วเก็บสีของตัวเองต่อไป
- **ขั้นตอนที่ไม่มีภาพ (เช่น ขั้นตอนพิมพ์) ยังใส่ภาพไม่ได้ในรอบนี้:** ให้ใช้ "+ เพิ่มภาพ" หรือ Ctrl+V เป็นขั้นตอนใหม่แทน ถ้าต้องการทีหลังค่อยเพิ่ม
- **วาดภาพสำเร็จด้วย canvas ของหน้าเว็บ ไม่ใช้ Pillow:** เพื่อให้โหมดดู Export และดาวน์โหลดวาดด้วยโค้ดเดียวกัน และ Pillow วาดข้อความภาษาไทยได้ไม่ดี เทสต์ที่พิสูจน์ข้อ 3.5 เรียกโค้ดของหน้าผ่านหน้าต่าง pywebview ได้ โดยไม่ต้องจำลองการคลิก

## 7. สิ่งที่ให้ผู้สร้างตัดสินใจเอง
- หน้าตาของแถบเครื่องมือ ไอคอน ระยะห่าง และแถบตัวเลือกของแต่ละเครื่องมือ ให้เข้ากับธีมสว่างที่มีอยู่
- ขนาดตัวเลขของเส้น ตัวอักษร หัวลูกศร และความแรงของการเบลอ ตามข้อ 6
- วิธีเลือก ลาก และลบสิ่งที่วาด รวมถึงการแก้ข้อความที่พิมพ์ไปแล้ว
- จะแยกโค้ดหน้าต่างแก้ภาพเป็นไฟล์ใหม่ใน `ui/` หรือไม่
- รูปแบบ endpoint สำหรับอัปโหลดภาพและบันทึก PNG ตราบที่ยังอยู่หลัง token และ `library.safe_*`
- จะเก็บเครื่องมือแก้วงแบบเดิมในการ์ดไว้ด้วย หรือย้ายทั้งหมดเข้าหน้าต่างแก้ภาพ ขอแค่ความสามารถเดิมยังอยู่ครบ
