# StepCap — ไฟล์ติดตั้ง .exe

สถานะ: ร่าง รอผู้ใช้อนุมัติ · ข้อสรุปจากรอบถามตอบ 2026-10-16 · ต่อจากงานเวอร์ชันภาษาอังกฤษ (PR #7)

## 1. ที่มาและเหตุผล

ผู้ใช้จะส่ง StepCap ไปติดตั้งในเครื่องคนอื่น (เพื่อนร่วมงาน ทั้งคนไทยและคนที่ไม่อ่านไทย)
ตอนนี้ต้องลง Python 3.14 แล้วพิมพ์คำสั่งเองหลายบรรทัด ซึ่งพนักงานทั่วไปทำไม่ได้

**เป้าหมาย:** ได้ไฟล์ `StepCap-Setup-<version>.exe` ไฟล์เดียว ส่งต่อทาง LINE / Drive / แฟลชไดรฟ์ได้
คนรับดับเบิลคลิก กดถัดไปไม่กี่ครั้ง แล้วใช้ StepCap ได้เลย โดยไม่ต้องลงอะไรเพิ่ม

## 2. สิ่งที่ผู้ใช้ตัดสินแล้ว

- ทำเป็นตัวติดตั้ง (ไม่ใช่โปรแกรมแบบพกพาที่แตกไฟล์เอง)
- **ไม่เซ็นใบรับรองรอบนี้** — ยอมให้ Windows ขึ้นหน้าจอ "Windows protected your PC" ตอนเปิดครั้งแรก
  และส่งวิธีกดผ่าน (More info → Run anyway) ไปพร้อมไฟล์
- **ตัวติดตั้งถามภาษาก่อน** (ไทย / English) หน้าจอติดตั้งที่เหลือเป็นภาษานั้น
  และ StepCap เปิดครั้งแรกเป็นภาษานั้น (แทนการเดาจากภาษาของ Windows)
- ผู้ใช้ยอมรับสรุปเดิม: ติดตั้งได้โดยไม่ต้องเป็น admin, มีไอคอนใน Start menu และเดสก์ท็อป,
  ถอนการติดตั้งได้จาก "Apps" ของ Windows, คู่มือใน `Documents\StepCap` ไม่ถูกลบ

## 3. พฤติกรรม

### 3.1 ตอนติดตั้ง
- ดับเบิลคลิก `StepCap-Setup-1.0.0.exe` → (หน้าจอเตือน SmartScreen ครั้งแรก) → เลือกภาษา ไทย / English
  → หน้ายินดีต้อนรับ → เลือกว่าจะสร้างไอคอนบนเดสก์ท็อปไหม (ติ๊กไว้ให้แล้ว) → ติดตั้ง → เสร็จ (ติ๊ก "เปิด StepCap" ไว้ให้)
- ติดตั้งสำหรับผู้ใช้คนนั้นเท่านั้น ไม่ขอสิทธิ์ admin
  ที่ติดตั้ง: `%LOCALAPPDATA%\Programs\StepCap` — *การตัดสินของผม* (ที่มาตรฐานของโปรแกรมแบบไม่ใช้ admin)
- ไอคอนใน Start menu ชื่อ "StepCap" และบนเดสก์ท็อป (ถ้าติ๊ก) ใช้ไอคอนส้มเดียวกับในแอป
- ถ้าเครื่องไม่มี Microsoft Edge WebView2 Runtime (เครื่อง Windows 10 เก่าที่ไม่ได้อัปเดต)
  ตัวติดตั้งบอกเป็นข้อความว่าต้องลงก่อน และหยุด — *การตัดสินของผม*: ไม่ดาวน์โหลดให้เอง (ไม่ออกเน็ตจากตัวติดตั้ง)
- ถ้า StepCap เปิดค้างอยู่ ตัวติดตั้งบอกให้ปิดก่อน (ผ่านเมนู tray > ออก)

### 3.2 ภาษาครั้งแรก
- ภาษาที่เลือกในตัวติดตั้งใช้เมื่อ `settings.json` ยังไม่มีค่า `lang`
  (เครื่องใหม่ หรือคนที่ใช้ StepCap รุ่นก่อนมีภาษาอังกฤษ) — *การตัดสินของผม*: ผู้ใช้เลือกเองชัด ๆ ชนะค่าตั้งต้น
- ถ้า `lang` ถูกตั้งไว้แล้ว (เคยเปลี่ยนในหน้าตั้งค่า) ติดตั้งทับ/อัปเดตก็ไม่เปลี่ยน
- รันจากซอร์ส (`python app.py`) ไม่มีค่าจากตัวติดตั้ง → ใช้กฎเดิม (ภาษาหน้าจอ Windows / ผู้ใช้เดิมเป็นไทย)

### 3.3 อัปเดต
- ติดตั้งรุ่นใหม่ทับรุ่นเก่าได้เลย คู่มือ การตั้งค่า และภาษาที่ตั้งไว้อยู่ครบ

### 3.4 ถอนการติดตั้ง
- จาก Settings > Apps ของ Windows (หรือ Start menu) — ลบไฟล์โปรแกรมและไอคอน
- **ไม่ลบ** `Documents\StepCap` (คู่มือของผู้ใช้)

### 3.5 สิ่งที่ส่งให้คนรับ
- `StepCap-Setup-1.0.0.exe`
- ข้อความสั้น 2 ภาษา (ไทย + English) วิธีติดตั้งและวิธีกดผ่านหน้าจอเตือน —
  เก็บใน repo ที่ `docs/install-guide.md` ให้ผู้ใช้คัดลอกไปวางในแชตหรืออีเมลพร้อมไฟล์

## 4. ทำอย่างไร (ส่วนที่ผมตัดสิน)

- **รวมโปรแกรม:** PyInstaller แบบโฟลเดอร์ (onedir) — เปิดเร็วกว่าแบบไฟล์เดียว และโปรแกรมแอนตี้ไวรัสทักน้อยกว่า
  - รวม `ui/` (รวม `en.json`), `samples/getting-started/`, `samples/getting-started-en/`
  - ไม่มีหน้าต่าง console
  - ไอคอนของ .exe ใช้ภาพเดียวกับไอคอนในแอป
- **ตัวติดตั้ง:** Inno Setup 6 (ฟรี) — ภาษาไทยใช้ไฟล์แปลของชุมชน Inno Setup; ข้อความเฉพาะของ StepCap แปลเอง
- **ส่งภาษาจากตัวติดตั้งให้แอป:** ตัวติดตั้งเขียนค่าภาษาไว้ในโฟลเดอร์โปรแกรม แอปอ่านตอนเปิด (ใช้เฉพาะกรณีข้อ 3.2)
- **ตรวจว่าแอปเปิดอยู่:** แอปสร้าง mutex ชื่อคงที่ให้ตัวติดตั้งตรวจได้
- **สคริปต์ build ตัวเดียว** (`build.py`) — รันแล้วได้ไฟล์ติดตั้งใน `dist/` ทำซ้ำได้ทุกครั้งที่แก้โค้ด
  - เลขเวอร์ชันอยู่ที่เดียวในโค้ด เริ่มที่ 1.0.0
  - ผู้เผยแพร่ (Publisher) ที่ขึ้นในหน้า Apps: "StepCap"
- เครื่องมือ build (PyInstaller, Inno Setup) เป็นของฝั่งคนสร้างเท่านั้น ไม่อยู่ใน `requirements.txt` ของแอป
  (แยกเป็น `requirements-build.txt`) ไฟล์ที่ได้ (`build/`, `dist/`) ไม่เข้า git
- **ติดตั้งเครื่องมือในเครื่องนี้ (ครั้งเดียว):** PyInstaller ลงใน `.venv` ด้วย pip,
  Inno Setup 6 ลงเครื่องด้วย `winget install JRSoftware.InnoSetup` (สำหรับผู้ใช้ปัจจุบัน)
- ไฟล์แปลภาษาไทยของ Inno Setup (`Thai.isl` จากหน้าแปลภาษาของ jrsoftware.org) เก็บไว้ใน repo
  เพื่อให้ build ซ้ำได้โดยไม่ต้องโหลดใหม่
- รองรับ Windows 10/11 แบบ 64-bit เท่านั้น (Python ที่ใช้เป็น 64-bit)

## 5. ทดสอบ

- **ทดสอบโปรแกรมที่รวมแล้ว (อัตโนมัติ):** เปิด `StepCap.exe` จาก `dist/` ด้วย `STEPCAP_STORAGE` ชี้โฟลเดอร์ชั่วคราว
  แล้วตรวจว่า: เซิร์ฟเวอร์ขึ้น, หน้าแรกโหลดได้, ตารางคำแปลโหลด (ตั้ง en แล้วได้ `const LANG="en"`),
  คู่มือตัวอย่างถูกคัดลอก, ส่งออก Word ได้ (python-docx ทำงานในตัวรวม), OCR ใช้ได้หรือบอกเหตุผล (winrt ทำงาน),
  ปิดแล้ว process หายจริง
- **ภาษาครั้งแรกจากตัวติดตั้ง:** ทดสอบ logic แบบ pure ใน `test_library.py`
  (มีค่าจากตัวติดตั้ง + ไม่มี lang → ใช้ค่านั้น; มี lang แล้ว → ไม่เปลี่ยน)
- **ตัวติดตั้งจริง (ครั้งเดียวก่อนส่ง, บอกผู้ใช้ก่อน):** ติดตั้งแบบเงียบลงโฟลเดอร์ชั่วคราว → เปิดแอปได้ →
  ถอนการติดตั้งแบบเงียบ → ไฟล์โปรแกรมหาย, `Documents\StepCap` ไม่ถูกแตะ
  (ทดสอบนี้สร้าง/ลบไอคอน Start menu ชั่วคราวในเครื่องนี้ จึงไม่รันอัตโนมัติทุกครั้ง)
- ชุดทดสอบเดิมทั้งหมดยังผ่าน; ไม่คลิก/พิมพ์บนเดสก์ท็อปจริง

## 6. ไม่ทำ (non-goals)

- เซ็นใบรับรอง (รอบหน้าถ้าต้องการ)
- อัปเดตอัตโนมัติ / ตรวจรุ่นใหม่ผ่านเน็ต
- ติดตั้งสำหรับทุกผู้ใช้ในเครื่อง (ต้องใช้ admin)
- เปิด StepCap อัตโนมัติตอนเปิดเครื่อง
- ดาวน์โหลด WebView2 ให้เอง
- เผยแพร่ไฟล์บน GitHub Releases — ทำเมื่อผู้ใช้สั่งแยก (เป็นการเผยแพร่ออกภายนอก)

## 7. สิ่งที่ถือว่าล้มเหลวแม้จะทำงานได้

- คนรับต้องลงอะไรเพิ่ม หรือเปิดหน้าต่างดำ (console) ขึ้นมา
- ถอนการติดตั้งแล้วคู่มือของผู้ใช้หาย
- โปรแกรมที่ติดตั้งแล้วขาดไฟล์บางส่วน (คำแปล คู่มือตัวอย่าง ส่งออก Word, OCR) ทั้งที่รันจากซอร์สได้
- ตัวติดตั้งขอสิทธิ์ admin

## 8. ให้ผู้สร้างตัดสินเอง

- ตัวเลือกของ PyInstaller ที่ต้องใช้ (hidden imports, hooks) และรายละเอียดสคริปต์ Inno Setup
- ชื่อไฟล์/ตำแหน่งที่เก็บค่าภาษาจากตัวติดตั้ง และชื่อ mutex
- ถ้อยคำในหน้าติดตั้งและใน `docs/install-guide.md`
