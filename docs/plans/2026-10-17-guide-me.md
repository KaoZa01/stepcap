# Guide Me Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "พาทำ" button on the guide viewer opens a docked side panel and walks the user through the guide on the real screen, highlighting each click target and advancing when they click it.

**Architecture:** Recording stores a `target` block per click step (exe name, window title, click offset in the window, UIA name/type/AutomationId of the clickable element). A new `guideme.py` holds pure target-resolution and session logic plus the Windows glue (window enumeration, UIA search, AppBar). A worker thread resolves the current step every 0.5 s and draws a click-through highlight via `overlay.py`; the recorder's existing mouse hook forwards clicks to it. The panel is a second, frameless pywebview window loading `index.html?guideme=<gid>`, rendered by a new `ui/guideme.js` that reuses `drawStepCanvas`.

**Tech Stack:** Python 3.14, ctypes, comtypes (UIA), tkinter overlay, pywebview, vanilla JS.

**Spec:** `docs/specs/2026-10-17-guide-me-design.md`

## Global Constraints

- Every user-visible string goes through `tr("ไทย")` (Python `from i18n import tr`, JS `tr()`), with an English entry in `ui/en.json`; `test_i18n.py` must stay green.
- Colours from `DESIGN.md` tokens only; highlight = `#fb923c`, 3 px, rounded corners; fallback/old-guide shape = circle of marker size (default 44).
- No browser, no AI, no new dependencies.
- Tests never click or type on the real desktop; every test that touches storage sets `STEPCAP_STORAGE` to a temp folder.
- `guide.json` stores only the exe **file name** (`Path(exe).name`), never a full path.
- Test files are plain scripts: `.venv\Scripts\python.exe test_x.py` (each has the `__main__` runner used by `test_steps.py`).
- Panel: AppBar docked right, width 360 px (physical px), on the target window's monitor at start, else the primary; does not move afterwards.
- While guiding, recording cannot start (app button, tray, hotkey all go through `start_rec_ui`).

## Review Focus

1. Monitor scaled ≠100% / second monitor: highlight rect must be in the same physical-pixel space as UIA rects and `GetWindowRect` (process is DPI-aware) — Task 2 test asserts `to_screen` arithmetic with negative-origin monitors.
2. Panel closed by any route (✕, Esc, app quit, main window closed) must remove AppBar, highlight and hook callback — Task 5 test asserts `stop_guide_ui()` clears all three; `on_closing`/`quit_app` call it.
3. Clicks on StepCap's own panel must never count as hitting the target — Task 3 test (hook forwards only when root window isn't own).
4. Old guide with no markers / note steps / steps with no image: state `none`, no highlight, no crash — Task 2 tests.
5. Several matching elements (many "OK" buttons) and zero-size / off-screen rects — Task 2 test `test_nearest_skips_empty`.

### Task 2: Pure target resolution and session (`guideme.py`)

**Files:**
- Create: `guideme.py`
- Test: `test_guideme.py`

**Interfaces:**
- Produces (all pure, no Windows calls):
  - `pick_window(wins: list[dict], exe: str, title: str) -> dict | None` — `wins` top-first `{"hwnd","exe","title","rect"}`; exe match case-insensitive; prefer exact title among matches; else first match.
  - `nearest(rects: list[tuple], pt: tuple[int,int]) -> tuple | None` — skips rects with zero width/height; returns the rect whose centre is closest to `pt`.
  - `resolve(step: dict, find_window, find_elements, origin: tuple[int,int]) -> dict` → `{"state": "element"|"approx"|"missing"|"none", "shape": "box"|"circle"|None, "rect": (l,t,r,b)|None, "app": str}`.
    - `find_window(exe, title) -> dict | None`, `find_elements(hwnd, aid, name, type) -> list[rect]` are injected.
    - kind not in `click/rightclick/doubleclick` → `none`.
    - no `target`: first marker → circle centred at `origin + (x, y)`, radius `size/2` → `approx`; no marker → `none`.
    - target, no window → `missing`, `app` = target exe stem.
    - window found: `pt = (wl+dx, wt+dy)`; `nearest(find_elements(...), pt)` → `element`/box; else circle at `pt` (size 44) → `approx`.
  - `hit(res: dict, x: int, y: int, pad: int = 6) -> bool` (box: inside rect±pad; circle: within radius+pad; others False).
  - `button_ok(kind: str, button: str) -> bool` — `rightclick`↔`"right"`, `click`/`doubleclick`↔`"left"`.
  - `class Session(steps: list[dict])`: `.index`, `.done: bool`, `go(i)` (clamped; `go(len)` sets done), `next()`, `back()`, `on_click(button, x, y, res) -> bool` (advances and returns True when `button_ok` and `hit`).

### Task 3: Windows glue — window list, UIA search, click forwarding, highlight

**Files:**
- Modify: `guideme.py` (add `top_windows`, `UIAFind`, `Runner`)
- Modify: `recorder.py` (`_ms_cb`: forward clicks while not recording)
- Modify: `overlay.py` (`highlight`)
- Test: `test_guideme.py` (live UIA test against our own tk window)

**Interfaces:**
- Consumes: Task 2 `resolve`, `Session`, `pick_window`; Task 1 `window_rect`, `recorder.window_info`, `recorder.is_own_window`.
- Produces:
  - `guideme.top_windows() -> list[dict]` — visible, non-minimised top-level windows in z-order (EnumWindows), not own windows, `exe` = `Path(window_info(h)[2]).name`.
  - `class UIAFind` (create on the thread that uses it; COM apartment like `recorder._UIA`): `elements(hwnd, aid, name, type) -> list[rect]` — `ElementFromHandle(hwnd).FindAll(TreeScope_Descendants, cond)` where cond = AutomationId if `aid` else `And(Name, ControlType)`; when an `aid` search returns nothing, retry with name+type; rects from `CurrentBoundingRectangle`; skip `CurrentIsOffscreen`.
  - `Recorder.on_guide_click: Callable[[str, int, int], None] | None` — in `_ms_cb`, when `nCode == 0`, not recording, and `wParam` is L/R button down, and `GetAncestor(WindowFromPoint(pt), GA_ROOT)` is not own → call it with `("left"|"right", x, y)`. The callback only does `queue.put` (hook must answer fast).
  - `Overlay.highlight(res: dict | None)` — draws/moves one click-through, capture-excluded, transparent Toplevel; `None` or state `missing`/`none` hides it. Box: rounded rect outline 3 px `#fb923c` inset by 4 px padding outward; circle: oval outline 3 px.
  - `class Runner(steps, origin, on_state)`: thread that owns `UIAFind`; loop `queue.get(timeout=0.5)`; each tick `resolve` current step (via `top_windows` + `pick_window`), call `overlay.highlight`, and publish `on_state({"index","done","state","app"})`; on a click event `Session.on_click` with the last `res`. Methods `go(i)`, `next()`, `back()`, `stop()` (posted to the queue), `click(button, x, y)` (the hook callback).
